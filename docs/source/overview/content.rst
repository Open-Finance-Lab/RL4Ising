Datasets
===================================

RL4Ising includes Ising model instances with different sizes, dimensions, and
structures. See the :doc:`dataset overview <../datasets/datasets>` for the model
types in the collection.

Baseline Solvers
===================================

We use traditional optimization solvers to compare the performance of
learning-based methods. The documentation covers :doc:`Gurobi
<../baseline_solvers/gurobi>`, :doc:`CPLEX <../baseline_solvers/cplex>`,
:doc:`COPT <../baseline_solvers/copt>`, and :doc:`SCIP
<../baseline_solvers/scip>`.

Benchmark
===================================

See :doc:`Benchmark Results <../benchmark/results>` for comparisons between
optimization solvers and reinforcement learning methods on Ising model
instances.
